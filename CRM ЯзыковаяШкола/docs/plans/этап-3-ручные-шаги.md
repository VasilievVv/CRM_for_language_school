# Этап 3. Ручные шаги подключения к БСП «Контактная информация»

Часть настроек затрагивает объекты поставщика (БСП) или не имеет API в инструментарии, поэтому
выполняется вручную в EDT. Все шаги — обязательны: без них список видов контактов не фильтруется
по владельцу и БСП не увидит новые объекты как владельцев контактной информации.

## Шаг 1. Разрешить изменение объектов поставщика

Объекты БСП закрыты поддержкой, поэтому запись в них запрещена (инструмент возвращает
«объект на поддержке, правило поддержки запрещает изменение»).

1. В EDT открыть `DefinedType.ВладелецКонтактнойИнформации` → свойства объекта → «Поддержка» →
   выбрать «Объект поставщика редактируется» (снять с поддержки).
2. То же для `Catalog.ВидыКонтактнойИнформации`.

## Шаг 2. Состав типа «ВладелецКонтактнойИнформации»

`DefinedType.ВладелецКонтактнойИнформации` → «Тип»: должны быть перечислены

- `СправочникОбъект.Пользователи` (уже есть),
- `СправочникОбъект.Клиенты`,
- `СправочникОбъект.Ученики`,
- `СправочникОбъект.Сотрудники`.

## Шаг 3. Виды контактной информации

В `Справочник.ВидыКонтактнойИнформации` создать предопределённые элементы:

| Предопределённое имя | Наименование | Родитель | Тип |
|---|---|---|---|
| `СправочникКлиенты` | Клиенты | — (папка) | — |
| `ТелефонКлиента` | Телефон клиента | СправочникКлиенты | Телефон |
| `EmailКлиента` | Электронная почта клиента | СправочникКлиенты | Адрес электронной почты |
| `СправочникУченики` | Ученики | — (папка) | — |
| `ТелефонУченика` | Телефон ученика | СправочникУченики | Телефон |
| `EmailУченика` | Электронная почта ученика | СправочникУченики | Адрес электронной почты |
| `СправочникСотрудники` | Сотрудники | — (папка) | — |
| `ТелефонСотрудника` | Телефон сотрудника | СправочникСотрудники | Телефон |
| `EmailСотрудника` | Электронная почта сотрудника | СправочникСотрудники | Адрес электронной почты |

Имена групп строго такие: БСП ищет группу видов по полному имени объекта без точек
(`УправлениеКонтактнойИнформациейСлужебныйПовтИсп.ГруппаВидаКонтактнойИнформацииПоИмениОбъекта`).

Остальные свойства видов скопировать с эталонов `ТелефонПользователя` / `EmailПользователя`
(ВидРедактирования, ИдентификаторДляФормул, Используется, ОтображатьВсегда).

## Шаг 4. Блок «Характеристики» у табличных частей

Для каждого из трёх справочников: `Клиенты`, `Ученики`, `Сотрудники` → ТЧ `КонтактнаяИнформация` →
свойства табличной части → «Характеристики» → добавить элемент:

| Свойство | Значение (для примера «Клиенты») |
|---|---|
| Источник типов характеристик (characteristicTypes) | `Справочник.ВидыКонтактнойИнформации` |
| Ключ (keyField) | `Справочник.ВидыКонтактнойИнформации.СтандартныйРеквизит.Ссылка` |
| Поле фильтра типов (typesFilterField) | `Справочник.ВидыКонтактнойИнформации.СтандартныйРеквизит.Родитель` |
| Значение фильтра типов (typesFilterValue) | `Справочник.ВидыКонтактнойИнформации.СправочникКлиенты` |
| Значения характеристик (characteristicValues) | `Справочник.Клиенты.ТабличнаяЧасть.КонтактнаяИнформация` |
| Поле объекта (objectField) | `Справочник.Клиенты.ТабличнаяЧасть.КонтактнаяИнформация.СтандартныйРеквизит.Ссылка` |
| Поле типа (typeField) | `Справочник.Клиенты.ТабличнаяЧасть.КонтактнаяИнформация.Реквизит.ВидДляСписка` |
| Поле значения (valueField) | `Справочник.Клиенты.ТабличнаяЧасть.КонтактнаяИнформация.Реквизит.Представление` |

Для `Ученики` — значение фильтра `СправочникУченики`, пути с `Справочник.Ученики`;
для `Сотрудники` — `СправочникСотрудники` и `Справочник.Сотрудники`.

Эталон для сверки — `Справочник.Пользователи` (там уже есть такой блок с `СправочникПользователи`).

## Шаг 5. Индексация реквизитов табличной части (необязательно, для производительности)

У ТЧ `КонтактнаяИнформация` реквизиты `Тип` и `Вид` в эталоне индексированы. Инструментарий
индексирование у реквизитов табличной части не выставляет — при необходимости поставить
«Индексировать» вручную в свойствах реквизитов.

## Шаг 6. Проверка

1. Открыть элемент клиента → «Контактная информация» → «Добавить» → в выборе вида предлагаются
   только «Телефон клиента» и «Электронная почта клиента».
2. Заполнить телефон и e-mail → записать → закрыть и открыть заново: значения на месте.
3. То же для ученика и сотрудника — наборы видов независимы.
4. Проверить, что подсказка видов не показывает виды других владельцев.
