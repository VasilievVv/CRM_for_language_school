# Этап 2. Подсистема «Справочники» и справочники языковой школы (архив)

Статус: **выполнен**, коммиты в ветке `feature/metadata-base` (6 коммитов, отправлены в origin).

## Цель

Создать в конфигурации «CRM ЯзыковаяШкола» дочернюю подсистему `ЯзыковаяШкола.Справочники` и 8 справочников: Клиенты, Ученики, Направления, ОбучающиеПрограммы, Группы, Кабинеты, УчебныеГода, Сотрудники — строго по макетам, с учётом ответов пользователя.

## Решения пользователя

| Вопрос | Решение |
|---|---|
| Реквизит «Договор» | **Строковый** (Строка 50). Позже будет создан документ «Договоры» — тогда заменим тип на ссылку |
| Подсистема | Дочерняя `Subsystem.ЯзыковаяШкола.Справочники` (рядом с НСИ) |
| `Группы.ВозрастнаяГруппа` | `CatalogRef.ОбучающиеПрограммы` |
| `Группы.ТЧ Расписание.Класс` | `CatalogRef.Кабинеты` |
| Формы справочников | **Не создаём** — только метаданные (формы отдельным этапом) |
| `Сотрудники` | Без телефона/почты (позже подключается БСП «Контактная информация») |
