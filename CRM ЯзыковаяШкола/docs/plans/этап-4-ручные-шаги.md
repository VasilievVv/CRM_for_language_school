# Этап 4. Ручные шаги

## Шаг 1. Синоним стандартного реквизита «Наименование» → «ФИО»

Инструментарий не умеет менять свойства стандартных реквизитов (API есть только для добавляемых реквизитов), поэтому шаг выполняется в EDT вручную.

Для `Справочник.Клиенты` и `Справочник.Ученики`:

1. Открыть справочник в редакторе EDT.
2. Вкладка «Данные» → «Стандартные реквизиты» → `Наименование`.
3. Свойство «Синоним» → `ФИО`.
4. Сохранить.

После этого в списках и в заголовках колонок вместо «Наименование» будет «ФИО». На формах элементов заголовок поля уже задан отдельно («ФИО»), так что формы работают корректно и без этого шага.

## Что уже сделано автоматически

- Поле «Код» убрано с форм элементов обоих справочников.
- Поля `Фамилия`, `Имя`, `Отчество`, `СокращенноеФИО` убраны с форм и заполняются автоматически из ФИО.
- Формы разбиты на страницы: «Личные данные», «Обучение» (только ученики), «Контактная информация», «Договоры» (только клиенты).
- Заголовок формы: «Клиент: Иванов И. И.» / «Ученик: Петров П. П.».
- У ученика `Возраст` — только для чтения, пересчитывается из даты рождения.
- На форме клиента — команда «Создать ученика».
