# Форма элемента «ДоговорОбучения» — ручные шаги в EDT

Раскладка страницы «Условия» (группы и перенос полей) уже сделана инструментами и закоммичена (`d74fb90`).
Ниже — то, что не поддерживается API редактирования форм и требует ручной настройки.

## Что уже есть в форме

```
Условия
├── Договор            Номер | Дата | СтатусДоговора (только просмотр)
├── Участники          Плательщик | Ученик
├── Условия обучения
│   ├── (левая)        Программа, Направление, УчебныйГод
│   └── (правая)       ФормаЗанятий, ДатаНачала, ДатаОкончания, КоличествоАкадемическихЧасов
├── Стоимость          СкидкаФиксированная | ИтоговаяСтоимостьЗанятия
└── Комментарий
```

Группы созданы с заголовками; ориентация — `HorizontalIfPossible`, разделение — `WeakSeparation`
(значения по умолчанию, изменить их инструментом нельзя).

## Шаги

1. Открыть в EDT `Document.ДоговорОбучения` → `ФормаЭлемента` → страница «Условия».
2. Для групп `ГруппаДоговор`, `ГруппаУчастники`, `ГруппаОбучение`, `ГруппаСтоимость`:
   - «Ориентация» → **Горизонтальная**;
   - «Отображение» → **Сильное разделение** (визуальная рамка блока) либо оставить «Слабое разделение».
3. Для групп `ГруппаОбучениеЛевая` и `ГруппаОбучениеПравая`: «Ориентация» → **Вертикальная**.
4. Для поля `Комментарий`: «Растягивать по вертикали» → **Да**.
5. Сохранить форму.

## Проверка

1. Блоки разделены визуально, заголовки читаются, поля идут в две колонки.
2. `Номер`, `Дата`, `СтатусДоговора` — в одной строке, статус недоступен для ручной правки.
3. `Комментарий` занимает оставшуюся высоту страницы.
4. Кнопки «Приостановить» / «Возобновить» / «Расторгнуть» работают как раньше.
5. Маркеры 1С по `Form.form` — 0 ошибок.
